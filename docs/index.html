Interface library for Roblox scripts. The fork adds a fully configurable key screen, theme-driven colours and a loading pill — all opt-in.

Key system

Layout table, header tag, thumbnail, buttons, loading pill, error reasons.

Moving elements

Error reasons

Status & loading

Inline status line, loading pill, custom success and error text.

Install

local WindUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/QilexCrown/WindUI/main/dist/main.lua"))()

Stock key system stays untouched unless KeySystem.Layout is a table.
